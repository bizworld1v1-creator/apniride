# ApniRide: design handoff

```
ApniRide-design-handoff/
├── README.md                 ← you are here
├── CLAUDE_CODE_PROMPT.md     ← ready-to-paste prompts for Claude Code (review, then implement)
├── design/
│   ├── DESIGN_SPEC.md        ← full spec: look & feel, components, 8 screens, flow, motion, accessibility
│   └── tokens.json           ← exact colours, fonts, sizes, radii, shadows, animation curves
└── prototype/
    ├── index.html            ← open this: all 8 screens side by side, live
    └── screens/              ← one standalone HTML file per screen (clickable flow)
        splash · login · home · fare · offers · trip · rate · driver
```

**To view:** unzip and double-click `prototype/index.html` (an internet connection loads the Google Fonts).
Start at `screens/splash.html` to click through the whole flow.

**To build it:** follow `CLAUDE_CODE_PROMPT.md`.

Brand: royal blue `#1E40AF` + sunshine `#FFC83D` + ink `#14132B`. Fonts: Bricolage Grotesque and Plus Jakarta Sans.
