# ride-app

Trust-first ride-hailing app for Pakistan. *Thanda safar, mehfooz safar, waqt pe safar.*

See [CLAUDE.md](CLAUDE.md) for the product vision, signature features, v1 scope and proposed tech stack.

## Local setup

1. Install [Git](https://git-scm.com/downloads).
2. Install Claude Code:
   - Windows (PowerShell): `irm https://claude.ai/install.ps1 | iex`
   - macOS / Linux: `curl -fsSL https://claude.ai/install.sh | bash`
3. Clone this repo and start Claude Code:

```
git clone https://github.com/bizworld1v1-creator/ride-app.git
cd ride-app
claude
```

4. First prompt to Claude Code:

> Read CLAUDE.md. Set up the monorepo structure, the NestJS backend skeleton with PostgreSQL + PostGIS via Docker, and empty Flutter passenger and driver apps. Commit and push.
